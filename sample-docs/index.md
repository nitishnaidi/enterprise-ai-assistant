# Sample Documents

This bundle holds the sample knowledge documents used for local dev and the
eval golden set. Ingest a concept file with:
`npm run ingest --workspace api -- ./sample-docs/<file>.md`

* [Returns Policy](./returns-policy.md) - Rules for returns, refunds, exchanges, and international orders within a 30-day window.
